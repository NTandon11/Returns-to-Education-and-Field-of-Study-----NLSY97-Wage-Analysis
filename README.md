# Returns to Education and Field of Study — NLSY97 Wage Analysis

ECO 340 Final Project, University of Toronto, April 2026

## Research Question
Do hourly wages differ across highest degree obtained? 
Among postsecondary degree holders, do wages also differ across fields of study?

## Data
- NLSY97 panel data (nlsy97_long.Rda) — download from Bureau of Labor Statistics nlsinfo.org
- College major data — downloaded separately from NLSY97 data portal (included in repo as eco340dataprojectmajorssmaller.dat)

## Files
- ECO-340-Data-Project.qmd — full R code, run by changing file paths at the top
- ECO-340-Report.pdf — written report
